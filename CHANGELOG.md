# Changelog

## [2.0.0] - 2026-10-27

### Added

- Expanded the curriculum to 51 lessons across 12 units and added 51 linked
  concepts to the interactive concept map.
- Added cumulative coding challenges to the final lesson of the first 11 units.
- Expanded the exercise bank to 510 exercises with 1,315 executable test cases.
- Added assumed scene hierarchies to Godot examples in the advanced lessons.

### Changed

- Calibrated all lesson estimates to the approved 10–25 minute range, for a
  total estimated study time of 771 minutes (12 hours, 51 minutes).
- Pinned all 76 curriculum documentation links to the official Godot 4.3 docs.

### Fixed

- Improved lesson explanations, exercise progression, and hints to address
  previously identified curriculum quality gaps.
- Clarified scene-tree assumptions and node paths in advanced Godot examples.
- Added regression coverage for loading legacy progress while preserving XP,
  badges, completed lessons, attempts, hints, and saved code.

### Security & Governance

- Added strict curriculum auditing for schema, concept-map dependencies,
  exercise quality, lesson timing, and Godot documentation links.
