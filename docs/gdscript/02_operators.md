## 1. العمليات الحسابية (Arithmetic Operators)

تُستخدم لإجراء العمليات الرياضية الأساسية.

| العملية | الوصف | مثال | النتيجة |
| --------- | ------- | ------ | --------- |
| `+` | الجمع (أو دمج النصوص/المصفوفات) | `5 + 3` | `8` |
| `-` | الطرح | `5 - 3` | `2` |
| `*` | الضرب | `5 * 3` | `15` |
| `/` | القسمة | `5 / 2` | `2` (أعداد صحيحة) أو `5.0 / 2.0` = `2.5` |
| `%` | باقي القسمة (Modulo) | `5 % 2` | `1` |
| `**` | الأُس (Power) | `2 ** 3` | `8` |
| `-x` | السالب (Unary Negation) | `-5` | `-5` |

### ملاحظات مهمة

```gdscript
#a القسمة بين أعداد صحيحة تُرجع عدداً صحيحاً
print(5 / 2)    # النتيجة: 2

# القسمة مع أعداد عشرية تُرجع عدداً عشرياً
print(5.0 / 2)  # النتيجة: 2.5

# عملية الأُس
print(2 ** 10)  # النتيجة: 1024
```

## 2. عمليات الإسناد المختصرة (Assignment Operators)

تُدمج العملية الحسابية مع الإسناد في عبارة واحدة.

| العملية | المكافئ | مثال |
| --------- | --------- | ------ |
| `=` | إسناد القيمة | `x = 10` |
| `+=` | `x = x + y` | `score += 5` |
| `-=` | `x = x - y` | `health -= damage` |
| `*=` | `x = x * y` | `speed *= 2` |
| `/=` | `x = x / y` | `price /= 2` |
| `%=` | `x = x % y` | `angle %= 360` |
| `**=` | `x = x ** y` | `value **= 2` |
| `&=` | `x = x & y` | `flags &= mask` |
| ` | =` | `x = x \| y` | `flags \|= new_flag` |
| `^=` | `x = x ^ y` | `bits ^= toggle` |
| `<<=` | `x = x << y` | `value <<= 2` |
| `>>=` | `x = x >> y` | `value >>= 1` |

```gdscript
var score = 10
score += 5   # score أصبح 15
score *= 2   # score أصبح 30
score -= 10  # score أصبح 20
```

## 3. عمليات المقارنة (Comparison Operators)

تُقارن بين قيمتين وتُرجع قيمة منطقية (`true` أو `false`).

| العملية | الوصف | مثال | النتيجة |
| --------- | ------- | ------ | --------- |
| `==` | يساوي | `5 == 5` | `true` |
| `!=` | لا يساوي | `5 != 3` | `true` |
| `<` | أصغر من | `3 < 5` | `true` |
| `>` | أكبر من | `5 > 3` | `true` |
| `<=` | أصغر من أو يساوي | `5 <= 5` | `true` |
| `>=` | أكبر من أو يساوي | `3 >= 5` | `false` |

### تحذير حول NAN

```gdscript
# NAN (Not a Number) لها سلوك خاص في المقارنات
var x = NAN
print(x == NAN)   # false! (سلوك غير متوقع)
print(x != NAN)   # true!

# الطريقة الصحيحة للتحقق:
print(is_nan(x))   # true ✓
```

## 4. العمليات المنطقية (Logical / Boolean Operators)

تُستخدم لدمج عدة شروط.

| العملية الرمزية | الكلمة المكافئة | الوصف | مثال |
| ---------------- | ---------------- | ------- | ------ |
| `&&` | `and` | العطف المنطقي - صحيح إذا كان **كلا** الطرفين صحيحين | `true and false` → `false` |
| `\|\|` | `or` | الفصل المنطقي - صحيح إذا كان **أحد** الطرفين صحيحاً | `true or false` → `true` |
| `!` | `not` | النفي المنطقي - يعكس القيمة | `not true` → `false` |

```gdscript
#a يمكن استخدام الرموز أو الكلمات (الكلمات أقل أولوية)
if is_alive and (score > 100 or has_bonus):
    print("فوز!")

# نفس النتيجة بالرموز
if is_alive && (score > 100 || has_bonus):
    print("فوز!")
```

### الحساب المختصر (Short-circuit Evaluation)

```gdscript
# GDScript تدعم الحساب المختصر:
# في 'and': إذا كان الطرف الأول false، لا يُحسب الطرف الثاني
# في 'or': إذا كان الطرف الأول true، لا يُحسب الطرف الثاني

if node != null and node.is_visible():
    # آمن! لأن node.is_visible() لن تُنفذ إذا كان node فارغاً
    pass
```

## 5. العمليات البتية (Bitwise Operators)

تعمل على مستوى البتات الفردية للأعداد الصحيحة (int في GDScript هو 64-بت).

| العملية | الوصف | مثال | النتيجة |
| --------- | ------- | ------ | --------- |
| `&` | AND بتي | `0b1100 & 0b1010` | `0b1000` (8) |
| `\|` | OR بتي | `0b1100 \| 0b1010` | `0b1110` (14) |
| `^` | XOR بتي (أو حصري) | `0b1100 ^ 0b1010` | `0b0110` (6) |
| `~` | NOT بتي (قلب جميع البتات) | `~0b00001111` | يقلب جميع البتات |
| `<<` | إزاحة يسارية | `1 << 3` | `8` |
| `>>` | إزاحة يمينية | `8 >> 1` | `4` |

```gdscript
# الاستخدام الشائع: أعلام البتات (Bit Flags)
const FLAG_WALKING = 1 << 0   # 1
const FLAG_RUNNING = 1 << 1   # 2
const FLAG_JUMPING = 1 << 2   # 4
const FLAG_FLYING  = 1 << 3   # 8

var state = 0

# إضافة علم
state |= FLAG_WALKING          # state = 1

# التحقق من علم
if state & FLAG_WALKING:
    print("الشخصية تمشي")

# إزالة علم
state &= ~FLAG_WALKING         # state = 0

# تبديل علم (toggle)
state ^= FLAG_JUMPING           # إذا كان موجوداً يُزال، والعكس
```

## 6. عمليات الفحص (Identity & Membership Operators)

| العملية | الوصف | مثال |
| --------- | ------- | ------ |
| `is` | فحص النوع | `if node is Sprite2D:` |
| `as` | تحويل النوع (يُرجع null إذا فشل) | `var s = node as Sprite2D` |
| `in` | فحص العضوية (هل العنصر موجود في المجموعة) | `if "sword" in inventory:` |
| `not in` | نفي العضوية | `if item not in bag:` |

```gdscript
#a فحص النوع مع is
if enemy is CharacterBody2D:
    enemy.velocity = Vector2.ZERO

# تحويل النوع مع as
var player = node as Player
if player:
    player.take_damage(10)

# فحص العضوية مع in
var items = ["sword", "shield", "potion"]
if "potion" in items:
    print("لديك جرعة!")

# يعمل أيضاً مع النصوص
if "hello" in "hello world":
    print("النص موجود!")

# يعمل مع القواميس (يفحص المفاتيح)
var stats = {"hp": 100, "mp": 50}
if "hp" in stats:
    print("نقاط الصحة: ", stats["hp"])
```

## 8. عمليات خاصة بالنصوص (String Operators)

| العملية | الوصف | مثال |
| --------- | ------- | ------ |
| `+` | دمج النصوص | `"Hello" + " " + "World"` → `"Hello World"` |
| `%` | تنسيق النصوص | `"I have %d cats" % 3` → `"I have 3 cats"` |
| `in` | البحث في نص | `"god" in "godot"` → `true` |

```gdscript
#a تنسيق النصوص بأكثر من قيمة
var text = "الاسم: %s، العمر: %d" % ["أحمد", 25]

# محددات التنسيق:
# %s - نص (String)
# %d - عدد صحيح (Integer)
# %f - عدد عشري (Float)
# %x - ست عشري (Hexadecimal)
# %o - ثماني (Octal)
# %c - حرف (Character)
# %% - علامة النسبة المئوية حرفياً
```

## 9. ترتيب أولوية العمليات (Operator Precedence)

من الأعلى أولوية إلى الأدنى:

| الأولوية | العملية | الوصف |
| ---------- | --------- | ------- |
| 1 | `()` | الأقواس |
| 2 | `-x`, `~` | السالب الأحادي، NOT البتي |
| 3 | `**` | الأُس |
| 4 | `*`, `/`, `%` | الضرب، القسمة، باقي القسمة |
| 5 | `+`, `-` | الجمع، الطرح |
| 6 | `<<`, `>>` | الإزاحة البتية |
| 7 | `&` | AND البتي |
| 8 | `^` | XOR البتي |
| 9 | `\|` | OR البتي |
| 10 | `<`, `>`, `==`, `!=`, `<=`, `>=` | المقارنات |
| 11 | `in`, `not in` | العضوية |
| 12 | `is` | فحص النوع |
| 13 | `!`, `not` | النفي المنطقي |
| 14 | `&&`, `and` | العطف المنطقي |
| 15 | `\|\|`, `or` | الفصل المنطقي |
| 16 | `if/else` | العملية الشرطية الثلاثية |
| 17 | `=`, `+=`, `-=`, ... | الإسناد |

```gdscript
#a مثال على أهمية الأولوية:
var result = 2 + 3 * 4     # = 14 (الضرب أولاً)
var result2 = (2 + 3) * 4  # = 20 (الأقواس أولاً)

# الأولوية في العمليات المنطقية:
# 'and' أعلى أولوية من 'or'
if a or b and c:   # تعادل: a or (b and c)
    pass
```
